# 🏧 ATM Banking System

A console-based **ATM Banking System** built in Java using Object-Oriented Programming concepts. Users can check their balance, deposit money, and withdraw cash through a simple menu-driven interface.

---

## 🚀 Features

- 💰 Check Account Balance
- 📥 Deposit Money
- 📤 Withdraw Cash
- ✅ Input Validation (negative amounts & overdraft prevention)
- 📋 Menu-Driven Console Interface

---

## 🗂️ Project Structure

```
ATMSystem/
│
├── ATM.java          # Core banking logic (balance, deposit, withdraw)
├── Customer.java     # Customer details (name, account number)
└── ATMMain.java      # Main class with menu-driven interface
```

## ▶️ How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/atm-banking-system.git
   ```
2. Navigate to the project folder
   ```bash
   cd atm-banking-system
   ```
3. Compile the files
   ```bash
   javac ATM.java Customer.java ATMMain.java
   ```
4. Run the program
   ```bash
   java ATMMain
   ```
